# Abhijit Singha — Personal Portfolio

A cinematic personal portfolio for **Abhijit Singha** built with Vite, HTML/CSS and JavaScript.

## Run locally

### 1. Clone
```bash
git clone https://github.com/Abhijitbot277/saloon-website.git
```

### 2. Open the project
```bash
cd saloon-website
```

Open the folder in VS Code or another code editor.

### 3. Install dependencies
```bash
npm install
```

### 4. Start the development server
```bash
npm run dev
```

Open the local URL shown by Vite, usually:

`http://localhost:5173/saloon-website/`

## Build for production

```bash
npm run build
```

## Design

- Dark cinematic portfolio
- Moving stars generated with CSS/JavaScript — no background image
- Custom SVG/vector-art cursor
- Responsive mobile navigation
- Animated reveal sections
- Skills, projects, journey and contact sections
- GitHub Pages deployment through GitHub Actions
