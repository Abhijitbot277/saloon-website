# Aurelia Salon

A cinematic luxury salon website built from scratch with React 19, Vite, Three.js, React Three Fiber, Drei and GSAP.

## Stack
- React + TypeScript + Vite
- Three.js + React Three Fiber + Drei
- GSAP for entrance motion
- Responsive CSS

## Run locally
```bash
npm install
npm run dev
```

The 3D hero uses a lightweight procedural glass/water orb so the repo stays self-contained and asset-free.
